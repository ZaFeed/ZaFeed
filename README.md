# ZaFeed — Global Market Data API · 全球股票与外汇行情 API

ZaFeed is a **global market data API** for developers building trading dashboards, research tools, and financial applications. Use a separate API key per market to integrate stock quotes, index data, forex, and precious metals.

ZaFeed 为交易看板、量化研究和金融应用提供**股票行情 API、指数与外汇行情接口**，也涵盖贵金属。按市场开通，在会员中心独立管理每个市场的 API Key。

[Official Website · 官网](https://www.zafeed.com/) · [Quick Start · 接入指南](https://www.zafeed.com/docs-guide.html) · [Markets & Pricing · 市场与价格](https://www.zafeed.com/pricing.html) · [API Examples · 接口示例](https://www.zafeed.com/docs-samples.html)

## How do I get a market data API key? · 如何获取行情 API Key？

1. [Choose a market · 选择市场](https://www.zafeed.com/pricing.html)
2. [Manage your market Key · 管理市场 Key](https://www.zafeed.com/member-keys.html)
3. [Follow a request example · 按示例发起请求](https://www.zafeed.com/docs-guide.html)

## Where can I find symbols and trading hours? · 如何查标的和交易时间？

Use the [Symbol Directory](https://www.zafeed.com/symbols.html) to find the exchange and symbol code, and the [Trading Calendar](https://www.zafeed.com/calendar.html) to check trading days and holidays.

先在[股票列表](https://www.zafeed.com/symbols.html)查交易所和标的代码，再用[交易日历](https://www.zafeed.com/calendar.html)核对交易日和休市安排。
